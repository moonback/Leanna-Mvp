## Règle de lecture

Une fonctionnalité décrite comme présente dans le code n'est pas nécessairement validée en environnement réel. Les statuts de test, de déploiement et de disponibilité doivent être confirmés séparément. Les données d'enquête restent confidentielles et les sorties IA ne constituent jamais des preuves ou des conclusions.
